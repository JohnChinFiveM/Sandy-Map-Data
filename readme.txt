To prevent pedestrians and vehicles from spawning in unwanted locations around this MLO, you should stream the `marina_drive.ymt` file located in the `scenario` folder.

**Important:** This must be done correctly. Streaming scenario files incorrectly can cause your server to crash.

* Only ONE scenario `.ymt` file should be streamed per server.

If you don't already have a scenario stream set up, you can also use the server-scenarios resource available here:

https://github.com/kibook/server-scenarios
